Eligibility Traces Actor-Critic
Following the developments in “Eligibility Traces” on page 80, Algorithm 5-4
presents an actor-critic algorithm based upon eligibility traces. Like before, it exposes
a hyperparameter to allow you to control the level of bootstrapping. The optimal
value for the trace-decay hyperparameter is problem dependent. Large values update
weights experienced far in the past. Small values only update recent weights.
The major difference between Algorithm 5-4 and Algorithm 5-3 is the inclusion of
the tracers that track which states to update in steps 9 and 10. These ultimately nudge
the value estimate weights, w, and the policy weights, θ, in the direction that the pol‐
icy visited in the past.
